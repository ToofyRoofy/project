# Sand Filling Station — 3D Gravimetric Filler (Bin Activator)

محاكاة ثلاثية الأبعاد لمحطة تعبئة وزنية (Three.js): Bin Activator + Auger + ميزان رقمي + فيدر نيوماتيك،
مع اللين الأول (سير الدخول 90°) ولين التعبئة والسير الخارجي.

**وضع العرض:** الصفحة بتشتغل أوتوماتيك ومستمرة من أول ما تفتح، ومفيش لوحات ولا تفاصيل —
بس اسم القطعة بيظهر لما تحرّك الماوس عليها. **على التليفون:** لمسة على القطعة بتفتح pop up باسمها (✕ أو لمسة على مكان فاضي بتقفله).

- الماوس الأيسر: دوران | الأيمن: إزاحة | العجلة: تقريب
- **H**: إظهار/إخفاء لوحات التحكم والقراءات (وضع التعديل، التفكيك، الـ views...)

ملف واحد (`index.html`) من غير build، ومكتبات Three.js r128 متضمّنة جواه — **بيشتغل أوفلاين بالكامل** (افتحه من الملف مباشرة).
وعلى GitHub Pages: `sw.js` بيخزّن الصفحة بعد أول زيارة، فتشتغل من غير إنترنت بعد كده (محتاج https).

## تشغيل محلي
افتح `index.html` في المتصفح مباشرة، أو:

    python3 -m http.server 8000   # ثم افتح http://localhost:8000

## نشر على GitHub Pages
1. Settings → Pages
2. Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
3. الرابط: `https://<username>.github.io/<repo>/`
